# 🛒 Amazon Cart Clone

A simple Amazon-style shopping cart built using **HTML, CSS, and JavaScript**.  
Features interactive quantity buttons, dynamic total price calculation, and a responsive layout for multiple products.

---

## 🚀 Features
- Add and remove items from the cart  
- Dynamic price updates  
- Responsive design (works on all devices)  
- Simple and beginner-friendly code

---

## 🧩 Tech Stack
- HTML  
- CSS  
- JavaScript

---

## 🧠 Learning Outcome
- DOM manipulation  
- Event handling in JavaScript  
- Responsive web design basics
